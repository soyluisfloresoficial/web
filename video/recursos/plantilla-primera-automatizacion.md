# Plantilla: diseña tu primera automatización en 5 pasos

Recurso gratuito de soyluisflores.es · Episodio 03 «Un formulario. Cinco tareas automáticas».

## 1. El disparador
- [ ] ¿Qué inicia el proceso? (por ejemplo: alguien envía un formulario, llega un correo, se agenda una cita)
- [ ] ¿Dónde ocurre? (web, Instagram, WhatsApp, correo)
- [ ] Escríbelo en una frase: «Cuando ___ ocurre en ___, empieza el proceso».

## 2. Los datos que recoges
- [ ] Lista los campos mínimos (nombre, correo, teléfono, interés, mensaje).
- [ ] Marca cuáles son obligatorios.
- [ ] Añade la casilla de consentimiento y el enlace a tu política de privacidad (RGPD).

## 3. Las reglas
- [ ] Define cómo se clasifica cada solicitud: «Si ___ entonces ___» (por ejemplo, si el interés es «Presupuesto», prioridad alta).
- [ ] Decide qué pasa cuando no encaja en ninguna regla.
- [ ] Escribe las reglas antes de tocar ninguna herramienta.

## 4. Las acciones
- [ ] Crear o actualizar el contacto en el CRM.
- [ ] Crear una tarea para la persona responsable, con fecha.
- [ ] Enviar la confirmación al cliente (qué dice y en cuánto tiempo responderás).
- [ ] Anota qué herramienta hace cada acción (formulario, CRM, Make, n8n, correo).

## 5. El registro y el seguimiento
- [ ] Guarda cada paso en el historial del contacto.
- [ ] Define qué pasa si nadie responde en un plazo (recordatorio a la persona responsable).
- [ ] Revisa una vez al mes qué solicitudes se quedaron sin atender.

## Antes de activarla
- [ ] Prueba el flujo completo con datos ficticios.
- [ ] Comprueba qué pasa si un campo llega vacío o duplicado.
- [ ] Decide quién recibe el aviso si algo falla.

Esta plantilla es orientativa. Cada herramienta se configura y se prueba antes de usarla con clientes reales.
